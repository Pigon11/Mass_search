# Лабораторная работа: "Mass search"
## Селезнев Е.А.
## Группа: 6133-010402D

### Что делал:
Решал задачу массового поиска подстрок - когда у нас есть большой буфер данных (просто последовательность байт) и множество подстрок разной длины, и нужно выяснить, какие из этих подстрок встречаются в буфере. 
Сначала написал эталонный алгоритм на CPU, потом сделал параллельную версию на GPU, а затем реализовали матричный метод, который описан в методическом пособии.

## CPU
Это самый понятный способ. Берём буфер и подстроки, организуем три вложенных цикла - по подстрокам, по позициям в буфере и по символам подстроки. Если все символы совпали - подстрока найдена.
